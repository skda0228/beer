# 맥주 계보도

Google Drive 「주류학개론 / 맥주」 폴더의 자료를 근거로 그린 계보 다이어그램.
연표(사건 나열)가 아니라 **회사 혈통을 선으로 추적한 그림**이다 — 선이 모이면 합병, 갈라지면 분할.

## 파일

| 파일 | 내용 |
|---|---|
| `jp-beer-genealogy.html` | 일본 계보 전체 페이지 (계보도 + 패턴 카드 + 원본 대조표 + 마일스톤) |
| `kr-beer-genealogy.html` | 한국 계보 전체 페이지 (계보도 + 패턴 카드 + 크래프트 흥망 + 판도) |
| `일본_맥주_계보도_1870-2026.svg` | 일본 계보도 단독 벡터 |
| `한국_맥주_계보도_1933-2026.svg` | 한국 계보도 단독 벡터 |
| `한국_수제맥주_흥망_2013-2023.svg` | 수제맥주 시장 규모 단독 벡터 |
| `png/*.png` | 위 세 도표의 2× 래스터 (1400px 뷰포트, deviceScaleFactor 2) |

SVG는 `prefers-color-scheme`에 반응해 라이트/다크 양쪽에서 읽힌다. 폰트는 시스템 스택을 쓴다.

## 읽는 법

세로선 하나 = 회사 하나의 혈통. 세로축은 **사건 순서**이며 연도 등간격이 아니다.

**일본** — 세 가지 구조가 한 장에 있다.
1. 기린 선은 1870년부터 하단까지 다른 선과 한 번도 닿지 않는다 (유일하게 합병·분할 없음).
2. 삿포로·아사히·에비스는 1906년 하나의 회색 줄기로 합쳐진다. 색이 사라지는 것은 사실의 표현이다 —
   독점 43년간 세 브랜드는 개별 회사로 존재하지 않았다. 1949년 갈라질 때 색은 **둘**만 돌아온다.
3. 산토리의 점선은 회사는 1899년부터 있었으나 맥주 사업이 아니었음을 뜻한다. 실선은 1963년부터.

**한국** — 평행과 교차의 그림이다.
1. 하이트진로(대일본맥주 자본)와 OB(기린 자본)는 1933년 같은 해에 태어나 90년간 만나지 않는다.
2. 진로 선만 움직인다. 1999년 **카스는 OB로**, 2005년 **진로 자신은 하이트로** — 두 선이 서로를 가로지른다.
3. 롯데는 81년 늦게 시작했고 5년 사이 브랜드를 세 번 갈아탔다.

두 계보도를 겹쳐 읽으면: 일본에서 갈라선 두 자본 계열이 한반도에서는 처음부터 1대1 라이벌로 배치됐다.

## 원본 인포그래픽에서 고친 것

Drive의 `일본 맥주 산업 150년 역사1.png`(NotebookLM 생성)와 대조해 바로잡은 항목:

- 1906년 합병 3사에 **「삿포로」가 두 번** 표기되어 있었다 → 삿포로·아사히·에비스로 정정
- 에비스의 1943년 상표 소멸 / 1971년 부활 누락 → 추가
- 오리온 누락 → 1957년 창업, 2019년 아사히 컨소시엄 지분 인수 추가
- 기린의 독자성이 정적인 옆 상자로만 표시 → 156년 연속선으로
- 「낫론맥주」「아사이맥주」「기먼」「섯포로」 등 표기 오류 다수 정정

## 알려진 불일치

기린 창업 연도가 자료 간에 어긋난다 — `맥주의 모든것 V2`는 **1870년**,
`일본 맥주 종합 정리`는 **1869년**. 코플랜드의 요코하마 양조장은 통상 이 두 해 사이로 기록이 갈리는
지점이라 어느 쪽도 오류로 단정하기 어렵다. 계보도는 원본 대조를 위해 1870년을 취했다.
노트북 내부 표기는 하나로 통일할 것.

## 재생성

```bash
# 스크린샷·PNG 내보내기는 Playwright(patchright) + 번들 Chromium 사용
node export.mjs          # figure 요소를 2× PNG로
python3 mksvg.py <html> <svg-index> <out.svg>   # HTML에서 단독 SVG 추출
```

HTML을 고치면 SVG와 PNG를 함께 재생성해야 한다 — 세 형식이 같은 소스에서 나온다.
